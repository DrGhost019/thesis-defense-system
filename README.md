### Thesis Defense Scheduling System (v2.0)

سامانه جامع، امن و مدرن جهت هماهنگی و زمان‌بندی جلسات دفاع تحصیلات تکمیلی (کارشناسی ارشد و دکتری) دانشگاهی بر پایه مشخصات فنی، احکام ضمیمه (Appendix) و اسناد تحلیل تفصیلی نسخه دوم.

## 🌟 ویژگی‌های کلیدی سیستم (Key Features)

- **دروازه ورود یکپارچه دانشگاهی (SSO Gateway):** ورود مستقیم اعضای دانشگاه (دانشجویان، اساتید و مدیران آموزش) بدون نیاز به ثبت‌نام عمومی به دلیل وجود اطلاعات در پایگاه داده دانشگاه.
- **تضمین عدم تداخل زمانی (Atomic Double-booking Guard):** استفاده از تراکنش‌های ACID و ایندکس‌های یکتای شرطی در سطح پایگاه داده PostgreSQL برای جلوگیری از هرگونه رزرو همزمان بازه‌ها یا اساتید.
- **تغییرناپذیری بازه‌ها (Slot Invariance):** بازه‌های تعریف‌شده غیرقابل ویرایش مستقیم بوده و تنها امکان ابطال (Withdraw) دارند تا یکپارچگی جلسات گذشته و آتی تضمین گردد.
- **الگوهای تکرار روزهای زوج و فرد (Recurring Patterns):** پشتیبانی از الگوهای روزهای فرد (شنبه، دوشنبه، چهارشنبه)، روزهای زوج (یکشنبه، سه‌شنبه) و تک‌روزه بین ساعت ۰۸:۰۰ الی ۱۷:۰۰ با اعتبارسنجی تداخل فواصل نیمه‌باز.
- **قانون حداکثر یک درخواست فعال برای دانشجو:** محدودیت یک جلسه در وضعیت‌های `requested`، `assigned` و `confirmed` با قید یکتای شرطی پایگاه داده.
- **اجماع داوران هیئت (Unanimous Consensus):** تایید مستقل کرسی‌ها توسط کلیه اعضای هیئت داوران پیش از قطعی شدن جلسه.
- **پشتیبانی دو زبانه کامل (Persian & English):** تغییر همه‌جانبه تمام رابط کاربری، فرم‌ها، جداول و عناوین همراه با سوئیچ خودکار بین `dir="rtl"` و `dir="ltr"`.
- **حالت تاریک و روشن (Dark / Light Mode):** پشتیبانی کامل با حالت پیش‌فرض روشن و قابلیت تغییر سریع از نوار ناوبری بالا.
- **همگام‌سازی هوشمند تقویم با زبان سامانه:** نمایش خودکار کلیه تاریخ‌ها به فرمت هجری شمسی (جلالی) در زمان انتخاب زبان فارسی و نمایش تاریخ‌ها به فرمت میلادی (Gregorian) در زمان انتخاب زبان انگلیسی بدون نیاز به تنظیمات دستی مجزا.
- **کپچای امنیتی کلودفلر (Cloudflare Turnstile CAPTCHA):** مجهز به لایه محافظتی هوشمند و مدرن ضدربات Turnstile در درگاه ورود دانشگاهی جهت جلوگیری از حملات Brute-Force و بات‌ها.
- **خروجی PDF لنداسکیپ A4 جدول هفتگی:** رندر برداری دقیق جدول همراه با نشان دانشگاه و فونت فارسی با استفاده از Playwright Headless.
- **یکپارچه‌سازی کامل با پیام‌رسان بله (Bale Messenger Bot):** پشتیبانی از اتصال حساب کاربری با کد یک‌بار مصرف ۸ کاراکتری (اعتبار ۱۰ دقیقه، محدودیت ۳ کد در ساعت، پشتیبانی از ارقام فارسی و انگلیسی)، اجرای خودکار ربات به روش Long-Polling هم‌زمان با اجرای سرور (بدون نیاز به ترمینال مجزا)، پشتیبانی از وب‌هوک HTTPS در محیط تولید، ارسال اعلان‌های دو زبانه نتیجه دفاع، صف تلاش مجدد (Retry Backoff) و یادآوری خودکار یک روز قبل از جلسه دفاع.
- **مستندات استاندارد OpenAPI 3.0:** تولید خودکار اسناد API با استفاده از اسکیمای اعتبارسنجی Zod.

## 🛠️ پشته فناوری (Technology Stack)

| بخش | فناوری‌های به‌کار رفته |
| :--- | :--- |
| **Frontend** | Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, Lucide Icons, Radix UI |
| **State & Forms** | TanStack Query v5, React Hook Form, Zod |
| **Fonts & UI** | قلم فارسی وزیرمتن (Vazirmatn), RTL/LTR Layout, Dark Mode |
| **Backend** | Next.js Route Handlers (RESTful API), Zod, zod-to-openapi, Pino Structured Logger |
| **Security & Auth** | Argon2 (Password Hashing), Jose (JWT Access & Refresh Tokens), Account Lockout |
| **PDF Generation** | Playwright (Headless Chromium) A4 Landscape Vector Export |
| **Database** | PostgreSQL 18, Prisma ORM, PostgreSQL Check Constraints & Partial Unique Indexes |
| **Messaging** | Bale Bot Webhook Integration, Node fetch |

## 🚀 راهنمای راه‌اندازی و اجرا (Getting Started)

### پیش‌نیازها:
- Node.js نسخه 18 یا بالاتر
- سرویس‌دهنده PostgreSQL نسخه 14 یا بالاتر

### گام‌های راه‌اندازی:

1. **نصب وابستگی‌ها:**
   ```bash
   npm install
   ```

2. **تنظیم متغیرهای محیطی:**
   یک نسخه از فایل `.env.example` را به نام `.env` کپی نمایید و مشخصات اتصال دیتابیس و کلیدهای سامانه را وارد نمایید:
   ```bash
   cp .env.example .env
   ```

   > 🔐 **تنظیم کلیدهای اختصاصی کپچا (Cloudflare Turnstile):**
   > این پروژه در درگاه ورود از کپچای امنیتی **Cloudflare Turnstile** استفاده می‌کند. کاربران و توسعه‌دهندگان باید کلید‌های اختصاصی API خود (`Site Key` و `Secret Key`) را از پنل کاربری [Cloudflare Dashboard](https://dash.cloudflare.com) دریافت نموده و در متغیرهای زیر در فایل `.env` وارد نمایند:
   > ```env
   > NEXT_PUBLIC_TURNSTILE_SITE_KEY="کلید_عمومی_سایت"
   > TURNSTILE_SECRET_KEY="کلید_محرمانه_سرور"
   > ```
   >
   > 🤖 **تنظیم توکن ربات پیام‌رسان بله (Bale Bot) و کلیدهای امنیتی:**
   > فایل `.env` به صورت خودکار در `.gitignore` قرار دارد تا توکن ربات، کلیدهای JWT، رمز پایگاه داده و کلیدهای کپچا هرگز در مخزن گیت منتشر نشوند. برای فعال‌سازی ربات بله، توکن اختصاصی خود را از `@BotFather` در پیام‌رسان بله دریافت کرده و در `.env` وارد کنید:
   > ```env
   > JWT_SECRET="یک_رشته_تصادفی_و_امن"
   > JWT_REFRESH_SECRET="یک_رشته_تصادفی_و_امن_دیگر"
   > BALE_BOT_TOKEN="توکن_ربات_بله"
   > BALE_WEBHOOK_SECRET="کلید_محرمانه_وب‌هوک"
   > NEXT_PUBLIC_BALE_BOT_USERNAME="نام_کاربری_ربات_بله"
   > NEXT_PUBLIC_BALE_BOT_URL="https://ble.ir/نام_کاربری_ربات_بله"
   > ```
   > - در اجرای محلی (`npm run dev` یا `npm start`)، سرویس ربات بله به صورت خودکار و داخلی (Embedded Long-Polling) فعال می‌شود و نیاز به اجرای دستور جداگانه ندارد.
   > - در صورت تمایل به اجرای مستقل ربات (`npm run bot:start`)، مقدار `BALE_DISABLE_EMBEDDED_BOT="true"` را در `.env` تنظیم کنید.
   > - در محیط تولید با دامنه HTTPS، می‌توانید وب‌هوک را با دستور `npm run bot:webhook -- set https://your-domain.com` ثبت کنید.

3. **ایجاد جداول و اعمال قیود پایگاه داده:**
   ```bash
   npx prisma db push
   npx tsx scripts/apply-sql-constraints.ts
   ```

4. **بارگذاری داده‌های اولیه آزمایشی (Seed Data):**
   ```bash
   npx tsx scripts/seed.ts
   ```

5. **اجرای آزمون‌های خودکار:**
   ```bash
   npm run test:bale-bot
   npm run test:auth-matrix
   ```

6. **اجرای سامانه در محیط توسعه یا تولید:**
   - **محیط توسعه:**
     ```bash
     npm run dev
     ```
   - **محیط تولید:**
     ```bash
     npm run build
     npm start
     ```
   سامانه روی آدرس `http://localhost:3000` در دسترس خواهد بود.
